# Paletas de Colores — Variaciones A vs B

---

## 🎨 OPCIÓN A: "Clara" (Estilo mochiArtesanal)

> Navbar y Hero con colores claros. El vino aparece en acentos y secciones oscuras.

### Paleta de colores

| Elemento | Color | Hex | Uso |
|----------|-------|-----|-----|
| **Primario** | Rosa profundo | `#D95578` | Botones CTA, acentos, badges |
| **Secundario** | Vino | `#590E2A` | Texto headings, acentos oscuros |
| **Fondo principal** | Crema claro | `#FDF5F0` | Fondo de página |
| **Fondo navbar** | Blanco 95% + blur | `#ffffff/95` | Navbar transparente → sólido |
| **Fondo hero** | Crema + gradientes sutiles | `#FDF5F0` → `#F8E8EE` | Hero claro con blush |
| **Fondo footer** | Crema oscuro | `#F5EDE4` | Footer claro |
| **Cards** | Blanco puro | `#FFFFFF` | Tarjetas, paneles |
| **Bordes** | Beige suave | `#E6E0D8` | Bordes sutiles |
| **Texto primario** | Vino | `#590E2A` | Headings, títulos |
| **Texto secundario** | Marrón cálido | `#8C6D51` | Descripciones, subtítulos |
| **Texto terciario** | Gris suave | `#6B6B6B` | Labels, captions |
| **Éxito** | Verde | `#4CAF50` | Envío gratis, éxito |
| **Advertencia** | Dorado | `#F7A04D` | Estrellas, ratings |
| **Error** | Rojo | `#E53935` | Errores |

### Navbar
```
┌─────────────────────────────────────────────┐
│  Logo: vino + rosa    Links: vino    CTA: rosa │  ← Transparente al inicio
├─────────────────────────────────────────────┤
│  Logo: vino + rosa    Links: vino    CTA: rosa │  ← Sólido con blur al scroll
└─────────────────────────────────────────────┘
  Fondo: transparente → blanco/95 con blur
  Hover links: línea rosa `#D95578` debajo
```

### Hero
```
┌─────────────────────────────────────────────┐
│                                             │
│   Fondo: crema claro con forma blush        │
│   Texto: vino                               │
│   CTA: rosa                                 │
│                                             │
│   Patrones: círculos sutiles blush          │
│   Olas SVG: rosa suave                      │
└─────────────────────────────────────────────┘
```

### Footer
```
┌─────────────────────────────────────────────┐
│  Fondo: crema oscuro #F5EDE4                │
│  Texto: vino                                │
│  Links: marrón cálido                       │
│  Newsletter: input rosa + botón rosa         │
│  Redes sociales: vino                       │
└─────────────────────────────────────────────┘
```

### Secciones oscuras (opcional)
```
Fondo: #590E2A (vino)
Texto: #FDF5F0 (crema)
Acento: #D95578 (rosa)
Uso: Banner métricas, CTA especial, etc.
```

## 🍷 OPCIÓN B: "Vino" (Estilo Actúa mochi-japanese)

## 📊 Comparación Directa

| Elemento | Opción A (Clara) | Opción B (Vino) |
|----------|-------------------|------------------|
| **Navbar fondo** | Blanco transparente | Vino sólido |
| **Navbar texto** | Vino `#590E2A` | Crema `#FDF8F4` |
| **Hero fondo** | Crema claro | Vino oscuro |
| **Hero texto** | Vino | Crema/blanco |
| **Hero CTA** | Rosa `#D95578` | Rosa `#D95578` |
| **Footer fondo** | Crema oscuro | Vino oscuro |
| **Footer texto** | Vino | Crema |
| **Fondo página** | Crema `#FDF5F0` | Crema `#FDF8F4` |
| **Secciones oscuras** | Opcional (solo CTAs) | Opcional (alternar) |
| **Sensación** | Fresca, artesanal, cercana | Premium, elegante, sofisticada |
| **Referencia** | mochiArtesanal | Actúa mochi-japanese |

---

## 🔗 Ambas comparten

- ✅ Hover línea en links del navbar
- ✅ Navbar transparente → sólido al scroll (A) / Vino siempre (B)
- ✅ Patrones en hero (olos, círculos)
- ✅ Mismos colores de acento: rosa `#D95578`, dorado `#F7A04D`
- ✅ Mismo sistema de tipografía: Playfair Display + Inter
- ✅ Mismos componentes a implementar

---

## 💡 Recomendación

**Opción A** → Si quieren un look más fresco y artesanal (como una pastelería boutique)

**Opción B** → Si quieren un look más premium y elegante (como una marca japonesa sofisticada)

Ambas son válidas. La decisión depende de la identidad de marca que quieran proyectar.
